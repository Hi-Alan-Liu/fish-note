# 設定與通知

## 設定項目

| 設定 | 預設 | 選項 / 說明 |
| --- | --- | --- |
| 幣別 | NT$（TWD） | 第一階段只切換**顯示符號**，不做匯率換算；舊資料金額不變 |
| 月結算日 | 1 號 | 1–31；例如 25 號 → 本期為 25 日到下月 24 日 |
| 每日記帳提醒 | 開 | 開 / 關 |
| 提醒時間 | 21:00 | 時間選擇器 |
| 金幣掉落通知 | 開 | 開 / 關，與每日提醒分開 |
| 音效 | 開 | 開 / 關 |
| 重新觀看教學 | — | 重看流程，不再給新手飼料與金幣 |
| 備份與還原 | — | 匯出 / 匯入備份檔、自動快照，見 [backup.md](backup.md) |

## 月結算日規則

- 結算日大於當月天數時（例如設 31 號遇到 2 月），以該月最後一天為準。
- 首頁與明細頁標題顯示實際區間（例如「10/25–11/24」），避免誤解。
- 修改結算日立即生效，所有統計依新區間重新計算（資料本身不變）。

## 通知

- 使用本機排程通知，不需伺服器。
- 每日提醒：每天在提醒時間觸發，**不論當天是否已記帳都會發送**（D-14）。
- 金幣掉落通知：魚消化完成時觸發；同一時段多隻魚合併成一則。
- 通知權限在教學完成後才詢問；使用者拒絕時，設定頁顯示「到系統設定開啟」。
