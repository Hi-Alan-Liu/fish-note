# 首頁與導覽

首頁就是水族箱，上方固定顯示本期支出，讓玩家每次打開 App 都先看到「這個月花了多少」。

## 畫面結構（直式）

```
┌───────────────────────────┐
│ 10/1–10/31            ⚙  │ ← 本期區間（依月結算日）、設定
│ 本月支出                   │
│ NT$ 12,480        [◔]     │ ← 迷你環圖，點擊進「明細」
│ 🪙 350    🍤 6    🐟 1/1   │ ← 金幣、飼料庫存、魚名額
├───────────────────────────┤
│                           │
│                           │
│          水族箱            │
│        （Flame 場景）       │
│     🐠                    │
│                           │
│              🪸      🪨   │
│ ░░░░░░░░沙地░░░░░░░░░░░░ │
├───────────────────────────┤
│ 🍤 飼料列（可左右滑動）      │ ← 拖曳或點選餵食
├───────────────────────────┤
│ 魚缸  明細  [ ＋ ]  商城  背包 │ ← 底部導覽，中間凸起「記帳」
└───────────────────────────┘
```

- 水族箱右上角有「布置」按鈕，進入 [DIY 模式](diy.md)。
- 飼料列依顏色分組顯示數量；沒有飼料時顯示「記一筆帳就能拿到飼料」並指向「＋」。

## 底部導覽

| 分頁 | 內容 |
| --- | --- |
| 魚缸 | 首頁 |
| 明細 | [記帳、明細與統計](ledger.md) |
| ＋ | 新增記帳（底部彈出表單，不離開當前頁） |
| 商城 | [商城與擴大魚缸](shop.md) |
| 背包 | [背包](backpack.md) |

## 規則

- 「本月支出」依 [月結算日](settings.md) 計算區間，並排除練習記帳（D-04）。
- 金額使用設定中的幣別符號，預設 NT$，千分位，無小數。
- 迷你環圖與明細頁圓餅圖使用相同的分類顏色（分類色 = 飼料色）。
