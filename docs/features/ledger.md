# 記帳、明細與統計

## 新增記帳

- 從底部「＋」彈出表單：收入 / 支出切換、金額（數字鍵盤）、分類、日期（預設今天）、備註（選填）。
- 目標：開啟到完成 ≤ 10 秒。
- 儲存後顯示獲得的飼料（顏色 = 分類色），飼料飛向首頁飼料列。
- 飼料發放規則與防刷見 [02 核心玩法與經濟系統](../02-gameplay-economy.md)。

## 分類與顏色

分類色 = 飼料色 = 圓餅圖區塊色，三處一致。

| 分類 | 顏色 |
| --- | --- |
| 餐飲 | 橘 |
| 交通 | 藍 |
| 購物 | 粉紅 |
| 娛樂 | 紫 |
| 居家 / 帳單 | 綠 |
| 醫療 / 學習 | 青 |
| 其他支出 | 灰白 |
| 收入 | 金黃 |

## 明細頁

```
┌───────────────────────────┐
│ ‹   10/1–10/31   ›        │ ← 左右切換期間
├───────────────────────────┤
│ 收入      支出      結餘   │
│ 42,000   12,480   29,520  │
├───────────────────────────┤
│        ◔ 圓餅圖            │
│  ■ 居家 50%  NT$ 6,240    │
│  ■ 購物 10%  NT$ 1,248    │ ← 分類排行，點擊篩選列表
│  ■ 餐飲  7%  NT$   874    │
├───────────────────────────┤
│ 10/12 (日)        -1,250  │
│  🟠 午餐            -180  │
│  🔵 捷運             -35  │
│ 10/11 (六)        -2,300  │
│  ...                      │
└───────────────────────────┘
```

- 圓餅圖只統計**支出**；最多顯示 6 個分類，其餘合併為「其他」。
- 點分類排行可篩選下方交易列表；再點一次取消篩選。
- 交易列表依日期分組，每天顯示當日小計；點交易可編輯或刪除。

## 規則

- 期間依 [月結算日](settings.md) 計算。
- **練習記帳**（教學產生，`isTutorial = true`）：
  - 不計入收入、支出、結餘、圓餅圖與首頁月總額。
  - 在列表中顯示，帶「練習」標籤，可刪除。
- 金額以整數儲存（新台幣無小數），每筆同時存幣別代碼，為未來多幣別預留。
