# 魚的心情（飽足度 / 飢餓 / 吃不下）

用可愛的表情提醒玩家「該記帳了」，但**不會餓死、不會生病**（D-10）。表情與畫法遵循 [03 美術風格](../03-art-style.md) 的橘橘規範。

## 飽足度

每隻魚都有一個「飽足度」，範圍 0–100%。

| 規則 | 內容 |
| --- | --- |
| 吃下飼料 | 飽足度設為 **100%**（吃飽） |
| 消化中 | 飽足度維持 100%，不下降 |
| 消化完成後 | 每小時下降 12.5%，**8 小時**從 100% 降到 0%（D-08） |
| 降到 0% | 進入「肚子餓」 |
| 新魚第一次放入魚缸 | 從 **50%（五分飽）**開始，約 4 小時後肚子餓（D-15） |
| 收進背包 | 飽足度與消化進度**凍結**，保留當下數值（D-05） |
| 從背包拿出 | **沿用收進去時的數值**，不會重設成 50%（D-15） |

> 防止重設：「五分飽」只在魚**第一次**放入魚缸時套用一次。吃飽的魚收進背包再拿出來仍是吃飽；餓的魚收進背包再拿出來仍是餓的。

## 心情狀態

| 狀態 | 條件 | 表情與動作 |
| --- | --- | --- |
| 開心 | 消化中 | 一般微笑，偶爾冒小愛心 |
| 普通 | 飽足度 1–100%，且未在消化 | 一般游泳 |
| **肚子餓** | 飽足度 0% | 頭上冒「魚骨頭」泡泡；嘴巴微張；游速降為 70%；偶爾游到水面附近張望 |
| **吃不下** | 消化中又有飼料靠近（或玩家把飼料丟在牠面前） | 搖頭 2 次、頭上冒「✕」泡泡、輕輕把飼料頂開，讓給其他空腹的魚 |

## 規則

- 飢餓只影響表情與游速，**不影響**金幣產量，也不會減少任何東西。
- 飽足度以「上次記錄的數值 + 記錄時間」即時推算，不需背景計算：
  `目前飽足度 = max(0, 記錄值 − 12.5% × 在魚缸中且非消化的經過小時數)`
- 收進背包時，先把當下飽足度寫回記錄值並停止計時；拿出來時從這個值重新計時。
- 首頁有魚肚子餓時，飼料列輕微閃動提示；若沒有飼料，提示「記一筆帳就能餵牠」。

## 動畫新增（補充 03 動作規範）

| 動作 | 表現 | 時長 |
| --- | --- | --- |
| Hungry 循環 | 魚骨頭泡泡上下飄、嘴巴微張、每 6–10 秒游向水面張望一次 | 循環 |
| Refuse 吃不下 | 搖頭（左右旋轉 ±12° 兩次）、✕ 泡泡、身體向飼料方向輕推 | 0.8 s |
