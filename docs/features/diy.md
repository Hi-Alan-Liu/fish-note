# DIY 布置模式

讓玩家拖曳擺放裝飾、切換背景，儲存後魚缸就固定為這個樣子。

## 流程

1. 首頁水族箱右上角點「布置」進入。
2. 魚**往畫面兩側游走**離開（不是直接消失），退出 DIY 時再游回來。
3. 畫面下方出現抽屜，分頁：**裝飾**、**背景**（背景分頁內含「水景背景」與「地板：沙子 / 小石子」兩組）。
4. 從抽屜拖曳裝飾進魚缸；抽屜中的裝飾顯示可用數量。
5. 點選已擺放的裝飾 → 出現小工具列：
   - 左右翻轉
   - 移到前層 / 移到後層
   - 收回背包
6. 背景分頁點選即時預覽切換。
7. 右上角「儲存」：寫入佈置並退出；「取消」：有未儲存變更時確認「放棄這次的變更？」。

## 畫面（直式）

```
┌───────────────────────────┐
│ 取消     布置魚缸     儲存 │
│              裝飾 1/1      │
├───────────────────────────┤
│                           │
│        水族箱（無魚）       │
│                           │
│           ┌──────┐        │
│           │ 🪸   │ ← 選取中│
│           └──────┘        │
│        [↔] [↑] [↓] [收回]  │ ← 小工具列
│ ░░░░░░░░沙地░░░░░░░░░░░░ │
├───────────────────────────┤
│ [裝飾] [背景]              │
│ 🪸x0  🪨x1  🐚x2  ...     │ ← 抽屜，拖曳進魚缸
└───────────────────────────┘
```

## 擺放規則

| 類型 | 規則 |
| --- | --- |
| 大型擺設（岩石、沉船、珊瑚礁） | 底部吸附在沙地上，只能左右移動與微調高度 |
| 小物（貝殼、海草、氣泡石） | 可放在沙地區域任意位置 |
| 背景 | 一次一張，不佔名額 |
| 地板（沙子 / 小石子） | 屬於底部背景，一次一種，不佔名額（D-18） |
| 超出名額 | 抽屜中的裝飾變灰，拖曳時提示「裝飾名額已滿」並提供「擴大魚缸」捷徑 |

- 第一階段**不做**旋轉與縮放（第二階段）。
- 預設圖層：越靠下（越靠近畫面前方）的裝飾越在前面；手動調整後以手動為準。

## 技術要點

- 位置以**比例座標（0–1）**儲存，不存像素，換裝置不會跑位。
- 圖層以整數儲存，前後層 = 交換數值。
- 編輯期間只改暫存；儲存時一次寫入整個佈置，取消直接丟棄暫存。
