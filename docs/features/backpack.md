# 背包

背包存放所有已擁有的魚與裝飾，玩家從這裡決定哪些要放進魚缸。

## 規則

- **只有魚缸中的魚**會吃飼料、會餓、會產出金幣；背包中的魚處於「休息」狀態（D-05）。
- 放入魚缸受名額限制：魚名額、裝飾名額。
- 魚可在背包直接「放入 / 收回」；裝飾的放入只在 [DIY 模式](diy.md) 進行（放進來就要決定位置）。
- 收回背包時，**消化進度與飽足度都凍結**；放回魚缸後從原本的數值繼續計時，不會重設（見 [fish-mood.md](fish-mood.md)）。
- 同一種魚可以擁有多隻（D-17），背包中每隻分開顯示，可各自放入 / 收回。
- 名額已滿時點「放入魚缸」，彈出兩個選項：
  1. **替換**：選擇一隻魚缸中的魚收回背包
  2. **擴大魚缸**：前往商城擴大魚缸分頁

## 畫面

```
┌───────────────────────────┐
│ 背包                       │
│ [魚 1/1]   [裝飾 1/1]      │ ← 分頁同時顯示名額
├───────────────────────────┤
│ ┌─────┐ ┌─────┐           │
│ │ 🐠 ✓│ │ 🐟  │           │ ← ✓ = 已在魚缸
│ │ 橘橘 │ │藍倒吊│           │
│ │[收回]│ │[放入]│           │
│ └─────┘ └─────┘           │
└───────────────────────────┘
```

- 裝飾分頁顯示擁有數量與已擺放數量，例如「圓石 2 / 擺放 1」，按鈕為「前往布置」。
