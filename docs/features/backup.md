# 備份與還原

記帳資料和魚缸內容（魚、裝飾、佈置、金幣、飼料、名額、進度）**一起備份、一起還原**，換手機或重裝 App 都不會遺失。

第一階段不需要帳號與伺服器（D-19）；第三階段再加上帳號雲端同步（見 [08](../08-phase-3-cloud-social.md)）。

## 三層備份

| 層級 | 方式 | 防護範圍 | 使用者操作 |
| --- | --- | --- | --- |
| 1. 手動備份檔 | 匯出一個 `.fishnote` 檔，透過系統分享存到 iCloud 雲碟、Google 雲端硬碟、LINE、Email 等 | 換手機、手機遺失、重裝 App | 手動匯出 / 匯入 |
| 2. 系統自動備份 | iOS：隨 iCloud 裝置備份；Android：Google 自動備份（Auto Backup） | 換手機時用同帳號還原 | 不需操作（依手機系統設定） |
| 3. 本機自動快照 | 每天第一次開 App 自動存一份快照，保留最近 7 份 | 誤刪資料、還原錯檔、程式異常 | 從快照清單選一份還原 |

> 層級 3 存在手機本機，手機遺失時無效；提醒使用者至少定期做層級 1。

## 備份內容

| 類別 | 內容 |
| --- | --- |
| 記帳 | 所有收支紀錄（含練習記帳）、分類 |
| 魚 | 每隻魚、是否在魚缸、飽足度、是否放入過魚缸、消化進度 |
| 魚缸 | 背景、地板、名額、裝飾擺放（比例座標、圖層、翻轉） |
| 物品與經濟 | 金幣餘額、飼料庫存、擁有的裝飾、缸底未回收金幣 |
| 進度 | 教學進度、連續記帳天數、新手飼料是否已領取 |
| 設定 | 幣別、月結算日、通知開關與時間、音效 |

## 匯出流程

1. 設定 → 備份與還原 → 「匯出備份檔」
2. 產生 `FishNote_2026-10-12.fishnote`
3. 開啟系統分享面板，使用者選擇存放位置
4. 完成後記錄「上次備份時間」

## 還原流程

1. 設定 → 備份與還原 → 「從備份檔還原」（或在檔案 App 點 `.fishnote` 檔以 Fish Note 開啟）
2. 顯示備份摘要，讓使用者確認：
   ```
   備份時間   2026/10/12 21:30
   記帳       128 筆
   魚         3 隻
   裝飾       5 件
   金幣       🪙 1,240
   ```
3. 警告：「還原會**取代**目前所有資料，無法合併。」
4. 還原前**自動把目前資料存成一份快照**，還原錯了可以回到還原前。
5. 寫入資料 → 重新載入 App → 魚游回魚缸

## 規則

- 還原是**整份取代**，不做合併（避免重複記帳與金幣重複計算）。
- 時間照常流逝：還原後依現在時間計算消化與飽足度，已消化完的會掉落金幣（受缸底 30 枚上限限制）。
- 備份檔附版本號；新版 App 可以讀舊版備份（自動升級資料格式），舊版 App 讀到新版備份時提示「請先更新 App」。
- 備份檔附檢查碼：檔案被修改或損壞時拒絕還原，並提示「備份檔已損壞」。
- 超過 30 天沒有手動備份時，在設定頁與首頁設定圖示上顯示小紅點提醒（不跳彈窗）。
- 匯出的檔案不加密（記帳資料屬於使用者自己）；第二階段可考慮加入「備份檔密碼」選項。

## 技術要點

- `.fishnote` = ZIP 檔，內含：
  - `manifest.json`：格式版本、App 版本、建立時間、各類筆數、檢查碼
  - `data.json`：所有資料表內容
- 檢查碼用 SHA-256 + App 內建金鑰（HMAC），能擋一般人手動改檔加金幣；金鑰在 App 內仍可能被破解，第三階段改由伺服器驗證。
- iOS：資料庫放在 App 的 Documents / Application Support 目錄（會被 iCloud 裝置備份納入），註冊 `.fishnote` 檔案類型。
- Android：開啟 `allowBackup`，設定 backup rules 納入資料庫與設定檔（Google 自動備份上限 25 MB，足夠）；註冊 `.fishnote` 開啟意圖。
- 快照與還原都在資料庫交易中完成，失敗時整份回滾，不會留下一半的資料。
