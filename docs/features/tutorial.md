# 新手教學

首次開啟時逐步引導，讓玩家在 2 分鐘內走完一次核心循環：記帳 → 飼料 → 餵魚 → 金幣 → 購買 → 布置。

## 步驟

| # | 步驟 | 玩家動作 | 系統反應 |
| --- | --- | --- | --- |
| 1 | 打招呼 | 點「開始」 | 橘橘游到畫面中央打招呼 |
| 2 | 第一筆帳 | 點「＋」，表單預填「收入 0 元・練習記帳」，按儲存 | 存成練習記帳（`isTutorial = true`） |
| 3 | 獲得新手飼料 | — | 獲得 1 份「新手飼料」（金色發光），飛到飼料列 |
| 4 | 餵魚 | 拖曳新手飼料到水中 | 橘橘游過去吃掉 |
| 5 | 掉落金幣 | — | **立即**掉落 5 金幣（不需等待消化） |
| 6 | 回收金幣 | 點金幣 | 金幣飛向餘額，餘額 0 → 5 |
| 7 | 逛商城 | 點「商城」→ 裝飾 → 小珊瑚 | 小珊瑚價格 5 |
| 8 | 購買 | 點「購買」 | 金幣 5 → 0，小珊瑚進背包 |
| 9 | 布置 | 點「立即布置」進 DIY，拖曳小珊瑚到沙地，按儲存 | 佈置儲存，橘橘游回來 |
| 10 | 完成 | — | 恭喜畫面；**此時才**詢問通知權限 |

## 規則

- 練習記帳不列入報表與月總額（D-04），見 [ledger.md](ledger.md)。
- 防刷規則「金額 0 元不給飼料」的**唯一例外**：教學第 2 步，整個帳號只觸發一次。
- 「新手飼料」為特殊道具：只在教學出現、吃下立即掉落 5 金幣、不能購買。
- 小珊瑚永久定價 5 金幣（D-11），裝飾名額初始 1（D-06），完成教學時名額剛好用滿。
- 每一步右上角都有「跳過教學」；跳過時直接贈送 5 金幣，避免玩家錯過入門資源。
- 教學進度存在本機；中途關閉 App，重開從同一步繼續。
- 教學期間只有目前步驟的目標可點擊，其餘區域加半透明遮罩並以光圈標示目標。
