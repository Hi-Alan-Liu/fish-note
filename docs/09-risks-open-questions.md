# 09 風險與待決事項

## 風險

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 使用者亂記帳刷飼料 | 記帳資料失真，失去記帳意義 | 每日給飼料上限、金額 0 不給、刪除重記不重複給 |
| 遊戲內容消耗太快 | 1–2 個月後無事可做 | 第二階段圖鑑、成長、節慶內容；商店價格曲線每階翻倍 |
| 美術資源工作量大 | 時程延後 | 第一階段只做 6 魚 15 裝飾；魚共用骨架換皮 |
| 調手機時間作弊 | 經濟失衡 | 第一階段偵測時間回跳，第三階段伺服器時間 |

## 待決事項

- [ ] 飼料等級的取得方式是否採用「連續記帳 + 合成」，還是依分類或金額決定？
- [ ] 收入類記帳是否給較高級飼料？
- [x] 魚是否會餓或生病 → 會顯示肚子餓（8 小時），但不會死亡或生病（D-08、D-10）
- [x] 同一種魚是否可購買多隻 → 可以（D-17）
- [x] 地板（沙子 / 小石子）是否佔裝飾名額 → 不佔，屬於底部背景（D-18）
- [ ] App 正式名稱與上架地區（台灣優先？）
- [ ] 美術資源來源：外包繪師、購買素材或 AI 輔助產圖
