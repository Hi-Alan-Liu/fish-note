# 07 第二階段：養成深度與內容擴充

目標是讓使用者「一個月後還有新東西可追」，同時把記帳功能補到可以取代一般記帳 App；預估 8 週。

## 養成與玩法

- [ ] 飼料等級擴充到 C、D，加入連續記帳獎勵與「3 合 1」飼料合成
- [ ] 魚種偏好：特定魚吃特定顏色飼料產量加成
- [ ] 魚的成長：幼魚 → 成魚，體型變大、產量提升
- [ ] 魚類圖鑑：收集進度、稀有魚種
- [ ] 多個魚缸、魚缸容量升級（可養更多魚）
- [ ] 每日 / 每週任務：例如「今天記 3 筆帳」「本週餐飲不超過預算」

## 記帳強化

- [ ] 自訂分類（可自選對應飼料顏色）
- [ ] 每月預算：達成預算額外給稀有飼料
- [ ] 多帳戶（現金、銀行、信用卡）、固定支出自動記帳
- [ ] 更完整的報表：月趨勢、分類比較
- [ ] 記帳資料匯出 CSV（備份與還原已移到第一階段，D-19）
- [ ] 備份檔密碼（選用）

## 裝飾與內容

- [ ] 魚種增加到 20+、裝飾 50+
- [ ] 節慶限定主題（聖誕、新年、中秋）
- [ ] 桌面小工具：顯示魚缸與今日支出

## 驗收標準

30 日留存較第一階段提升；使用者平均每日開啟 ≥ 2 次。
