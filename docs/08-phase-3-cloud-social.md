# 08 第三階段：雲端、社交與營運

目標是讓資料不會不見、讓朋友互相拜訪，並建立可持續的收入；預估 10–12 週。

## 雲端

- [ ] 帳號登入（Apple、Google），記帳與魚缸跨裝置同步
- [ ] 伺服器時間驗證金幣掉落，封鎖調時間作弊
- [ ] 雲端自動備份（取代第一階段的手動備份檔，並可匯入既有 `.fishnote` 檔）

## 社交

- [ ] 好友系統：參觀好友魚缸、幫忙清理金幣（雙方各得小獎勵）
- [ ] 魚缸截圖分享到 IG / LINE
- [ ] 共同記帳：情侶 / 室友共用一個帳本與一個魚缸
- [ ] 社群挑戰：例如「21 天連續記帳」全服活動

## 營運與商業模式

- [ ] 進階會員訂閱：無廣告、進階報表、額外魚缸、每月限定魚
- [ ] 內購限定主題裝飾包（只賣外觀，不賣金幣，避免破壞「記帳才有收穫」的核心）
- [ ] 選擇性廣告：看廣告加速消化（每日上限）
- [ ] 後台上架新魚與活動，不需發版
- [ ] 數據分析：留存、記帳頻率、商店轉換

## 驗收標準

更換手機登入後資料完整還原；付費轉換率與留存達成上線前訂的目標。
