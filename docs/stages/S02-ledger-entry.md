# S02 記帳

## PM — 上一階段檢查與本階段目標

**S01 檢查**：骨架通過。延續 S01 建議第 3 點，本階段存帳後必須讓玩家「看得到拿到的飼料」。

**本階段目標**

1. 「＋」打開記帳表單：收入 / 支出、金額、分類、日期、備註，10 秒內完成一筆。
2. 存帳時依規則發放飼料，並以動畫提示拿到什麼。
3. 首頁顯示飼料庫存數量。
4. 明細頁先列出紀錄（依日期分組），可點擊編輯、刪除。統計與圓餅圖留到 S03。

**飼料發放規則**（依 [02 經濟系統](../02-gameplay-economy.md)）

| 規則 | 內容 |
| --- | --- |
| 基本 | 每筆帳得 1 份飼料，顏色 = 分類顏色，等級 A |
| 連續記帳 | 連續 3 天（含今天）都有拿到飼料，今天的**第一份**飼料升級為 B |
| 每日上限 | 每天最多 10 份；以「存帳當下」的日期計算，不看帳上填的日期（避免補記舊帳刷飼料） |
| 金額 0 | 不給（教學例外在 S09 處理） |
| 刪除再重記 | 刪除不會退回當天已用掉的額度，所以刪了重記不會多拿 |
| 編輯 | 改分類、金額不影響已發放的飼料 |

**驗收條件**

- [ ] 新增、編輯、刪除收支都能正確寫入資料庫
- [ ] 單元測試涵蓋全部發放規則：A 級、顏色、0 元、每日 10 份、刪除重記、連續 3 天升級 B、補記舊日期仍算今天額度
- [ ] 存帳後首頁飼料數字即時增加
- [ ] 明細頁看得到新紀錄，點擊可編輯與刪除（刪除需確認）
- [ ] analyze 無錯誤、全部測試通過

## UI/UX — 畫面構思

### 記帳表單（底部彈出，約 85% 高）

```
┌───────────────────────────┐
│ ━━━━                     │ ← 拖曳把手
│ [ 支出 | 收入 ]      ✕    │ ← 分段切換
│                           │
│ 🟠 餐飲                    │ ← 目前分類（色點 + 名稱）
│ NT$            1,250      │ ← 大字金額，靠右
├───────────────────────────┤
│ 🟠餐飲  🔵交通  🩷購物  🟣娛樂 │
│ 🟢居家  🩵醫療  ⚪其他        │ ← 分類格（收入時只有「收入」）
├───────────────────────────┤
│ 📅 今天 10/12   📝 備註…    │
├───────────────────────────┤
│  7    8    9    ⌫         │
│  4    5    6    C         │ ← 自訂數字鍵盤
│  1    2    3   ┌────┐     │
│  00   0   .    │記一筆│     │ ← 主按鈕（金額 0 時不可按）
│                └────┘     │
└───────────────────────────┘
```

- 使用**自訂數字鍵盤**，不跳系統鍵盤，金額與分類同一畫面完成，符合 10 秒目標。新台幣不需要小數，「.」鍵在第一階段停用、顯示為淡色。
- 金額上限 9 位數（9 億 9 千萬），超過不再接受輸入。
- 分類格每格是「色點 + 名稱」的膠囊，選中時外框變成該分類顏色並加粗。
- 預設分類：上次使用的支出分類；切到「收入」自動選「收入」。
- 日期：點擊開啟日期選擇器，預設今天；備註：點擊才展開輸入框（展開時暫時收起數字鍵盤）。
- 編輯模式：標題改為「編輯紀錄」，主按鈕改為「儲存」，下方多一個紅色「刪除這筆」文字按鈕，刪除前跳確認對話框。

### 存帳後的回饋

- 表單關閉，畫面下方跳出提示條：飼料圓點 +「獲得 橘色飼料 A ×1」。
- 升級 B 時：「連續記帳 3 天！獲得 橘色飼料 B ×1」，圓點外加一圈亮邊。
- 沒拿到飼料時說明原因：「金額為 0，這筆不會獲得飼料」/「今天的 10 份飼料已經領完囉」。

### 首頁

- 金幣旁新增飼料庫存：飼料圖示 + 總數量。點擊飼料數字展開各顏色數量（S04 改成水族箱下方的飼料列）。

### 明細頁（本階段簡易版）

```
┌───────────────────────────┐
│ 明細                       │
│ 10/12（日）          -1,215│ ← 日期與當日小計
│  🟠 午餐  餐飲        -180  │
│  🔵 捷運  交通         -35  │
│  🟡 薪水  收入     +42,000  │
│ 10/11（六）           -500 │
│  ...                      │
└───────────────────────────┘
```

- 每列：色點、備註（沒有備註時顯示分類名）、分類名（小字）、金額（支出黑字前加「-」，收入用橘色加「+」）。
- 點一列開啟編輯表單。
