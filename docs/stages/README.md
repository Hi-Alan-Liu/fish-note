# 開發輪巡紀錄

第一階段 MVP 拆成小階段逐一完成。每個小階段固定流程：

1. **PM**：檢查上一階段成果、提出建議，定義本階段目標與驗收條件
2. **UI/UX**：畫面構思（版面、互動、狀態、文案）
3. **DEV**：實作與測試，回報結果
4. 回到 PM 檢查 → 下一階段

每個小階段一份紀錄（`Sxx-*.md`），包含三個角色的內容與 PM 驗收結果。
