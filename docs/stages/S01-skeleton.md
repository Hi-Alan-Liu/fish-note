# S01 專案骨架

## PM — 目標

這是第一個小階段，沒有上一階段可檢查。目標是打好地基，讓之後每個功能都能直接接上，不必回頭改結構。

**本階段目標**

1. 建立 Flutter 專案 `app/`，只允許直式。
2. 依 [03 美術風格](../03-art-style.md) 建立主題（顏色、字體、圓角）。
3. 底部導覽五個位置：魚缸 / 明細 / ＋ / 商城 / 背包，各頁先放有設計過的空狀態。
4. 依 [04 技術架構](../04-tech-architecture.md) 建立全部資料表，首次啟動寫入初始資料：8 個分類、預設設定、1 個魚缸（魚 1 / 裝飾 1 名額）、錢包 0 金幣、橘橘 1 隻（在魚缸、五分飽）。
5. 建立單元測試基礎。

**驗收條件**

- [ ] `flutter analyze` 無錯誤
- [ ] `flutter test` 全數通過，至少涵蓋：初始資料筆數正確、重複啟動不會重複寫入、分類顏色與飼料顏色一致
- [ ] App 可以建置出 Android APK
- [ ] 五個導覽位置可切換，「＋」凸起且醒目

**不在本階段**：記帳表單、水族箱動畫、任何金幣邏輯。

## UI/UX — 畫面構思

### 全域設計 Token（來自橘橘風格）

| Token | 值 | 用途 |
| --- | --- | --- |
| primary | `#FF7A2E` | 主按鈕、「＋」、強調 |
| primaryDeep | `#E2622A` | 按下狀態、文字強調 |
| ink | `#1D3640` | 主要文字 |
| muted | `#5B7680` | 次要文字 |
| paper | `#F3F8F9` | 頁面底色 |
| surface | `#FFFFFF` | 卡片、底部導覽 |
| line | `#D5E4E8` | 分隔線、邊框 |
| outline | `#2B1D1A` | 角色描邊（僅插圖使用） |
| seaTop / seaMid / seaBottom | `#5FD3E8` / `#2FB2D4` / `#1A8FBD` | 水族箱漸層 |

字體：標題 Huninn（圓體）、內文 Noto Sans TC、數字 Baloo 2。圓角：卡片 18、按鈕 14、膠囊全圓。第一階段只做淺色主題。

### 底部導覽

```
┌───────────────────────────────┐
│  🐠      📊     ╭───╮    🛍     🎒 │
│ 魚缸    明細    │ ＋ │   商城   背包│
│                ╰───╯            │
└───────────────────────────────┘
```

- 高度 68 + 安全區；底色 surface，上緣一條 line 色細線。
- 中間「＋」：直徑 60 的橘色圓鈕，凸出導覽列上緣 18，白色加號，底部 3 px 內陰影做出厚度。
- 選中分頁：圖示與文字用 primary，未選中用 muted。
- 「＋」不是分頁，點擊後彈出記帳表單（S02 實作，本階段先顯示「下一階段開放」提示）。

## DEV — 實作與測試

**環境**：Flutter 3.47.7 / Dart 3.13.5（安裝於 `D:/Tools/flutter`）。

**實作內容**

| 檔案 | 內容 |
| --- | --- |
| `lib/theme/tokens.dart`、`app_theme.dart` | 設計 Token 與 Material 主題；字體 Huninn、Baloo 2 內嵌於 `assets/fonts` |
| `lib/domain/feed.dart`、`categories.dart` | 飼料顏色 / 等級、8 個預設分類 |
| `lib/data/db/tables.dart` | 12 張資料表（依 04 技術架構） |
| `lib/data/db/app_database.dart` | Drift 資料庫、可重複呼叫的 `seedIfNeeded()` |
| `lib/data/providers.dart` | Riverpod：資料庫、魚缸、魚、錢包 |
| `lib/art/clownfish_painter.dart` | 橘橘從 SVG 原型移植為 Canvas 繪製，支援姿勢參數（尾巴、胸鰭、眨眼、驚嚇、嘴型、汗滴），S04 動畫直接沿用 |
| `lib/features/shell/` | 底部導覽（中間凸起「＋」）、四個分頁 |
| `lib/features/*` | 首頁（靜態魚缸）、明細 / 商城空狀態、背包讀取資料庫 |
| Android / iOS 設定 | 只允許直式；App 名稱 Fish Note |
| `web/` | Drift 網頁版所需的 `sqlite3.wasm`、`drift_worker.js`（用於瀏覽器預覽） |

**測試結果**

- `flutter analyze`：無問題
- `flutter test`：7 / 7 通過
  - 資料：初始資料正確、重複初始化不會重複寫入、分類顏色 = 飼料顏色、飼料等級數值
  - 介面：四個分頁切換、背包讀到橘橘與「魚 1/1」、「＋」顯示下一階段提示
- 網頁版建置並以 390×844 手機尺寸截圖檢查：首頁、背包畫面正確

**未完成**

- Android APK 建置：電腦缺 Android `cmdline-tools`，且 Android SDK 授權需要使用者本人同意，暫時無法建置。
